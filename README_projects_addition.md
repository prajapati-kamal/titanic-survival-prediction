
## Additional utility projects

I added three small utility projects with browser demos you can open directly:

- password-generator/ — password_generator.py, demo.html (3D rotating card)
- mac-address-generator/ — mac_address_generator.py, demo.html (3D knot animation)
- mall-inventory/ — mall_inventory.py, demo.html (3D dashboard panel)

Open each demo HTML file in your browser to view the animated preview. Use the Python scripts from the repo to run the utilities locally.
